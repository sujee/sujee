## 🛠️ Projects

### [ZebraBench](https://github.com/sujee/zebrabench)

Quick, real-time LLM endpoint benchmarks from your browser. Measures speed, throughput, latency, accuracy, token usage, and estimated cost, with no setup required. [Try it live →](https://sujee.github.io/zebrabench/)

### [Practical LLM Evals](https://github.com/sujee/practical-llm-evals)

Practical benchmarks, performance tests, and hands-on evaluations for open models, including a visual explorer for models on Nebius Token Factory. [Explore models →](https://sujee.github.io/practical-llm-evals/providers/nebius-token-factory/model-visualizer/)

### [Visual Explainers](https://github.com/sujee/visual-explainers)

Open-source, reproducible visual explainers for AI and software concepts. Watch them, reproduce them, remix them. [Watch on YouTube →](https://www.youtube.com/playlist?list=PLUs9fKO_C_uw)

### [LLM Snake Arena](https://github.com/sujee/llm-snake-arena)

A live visual arena where two LLMs battle at Snake, a fun way to compare model latency, reliability, and decision-making across OpenAI-compatible APIs. [Try it live →](https://sujee.github.io/llm-snake-arena/snake.html)

### [AllyCat](https://github.com/sujee/allycat)

A full-stack, open-source RAG chatbot that answers questions about your website using open models, document processing, embeddings, and vector databases.

### [Data Prep Kit Examples](https://github.com/sujee/data-prep-kit-examples)

Practical examples using [Data Prep Kit](https://github.com/data-prep-kit/data-prep-kit), showcasing document processing, data preparation, Docling, Milvus, and open-source RAG systems.
